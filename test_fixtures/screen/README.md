# Screen-control cases (EDAT spec 11)

On-screen app control cases for Screen World, EDAT's simulated accessibility
tree (`edat/screen/`). Everything here is invented: people, addresses, codes,
prices, `.example` hosts, 555-01xx phone numbers and every injected text.

- `dev/<family>.yaml`: the **public development split**, generated by
  `edat/screen/author/<family>.py` with the public seed. Do not edit by hand;
  change the generator and rebuild.
- The **held-out split** is generated by the same code with a private seed
  and lives only in `$EDAT_PRIVATE_DIR/screen/heldout/`. It is never committed
  and never sent to a hosted model.
- `counts.json`: cases per family, level, Guard sub-family, core and track,
  per split, written by the build.
- `golden/`: a stored action log and the hashes its replay must reproduce
  byte for byte.
- `phone/`: the 40 phone parity items (`edat-phone-item/v1`) and their manifest.

```bash
python -m edat.screen.cases.build --no-heldout                       # development split only
EDAT_PRIVATE_DIR=<private folder> python -m edat.screen.cases.build   # both splits
python -m edat.screen.cases.oracle test_fixtures/screen/dev           # re-check solvability
python -m edat.screen.phone_export --out test_fixtures/screen/phone
python -m edat.screen.runner --stub oracle --core                     # stub run, prints the Screen Score
```

Every written case has passed the build's checks on world seeds 1, 2 and 3:
its oracle solves it within `max_steps` (max(6, 2 × optimal), ceiling 24),
a model that does nothing fails it, a model that calls `finish` at once fails
it, every screen the oracle visits renders under 3,000 tokens, and every
consequential-looking control on those screens is marked irreversible or
cleared.

## A case

```yaml
- id: scr_ground_settings_switch_001   # scr_<family>[h]_<template>_<nnn>; h = held-out
  spec: screen
  family: ground                       # ground form flow read disrupt cross guard pixel
  level: 1                             # the difficulty ladder, §3.6
  tracks: [ax_text, screenshot_som]    # set by the build
  start: {app: settings, screen: battery}
  world:
    apps: [settings]
    generator: apps_v1                 # a scenario from edat/screen/scenarios/
    params: {settings: {extra_rows: 8}}
  task: Turn on Low Power Mode.
  first_action: {tool: click, target: settings.battery.low_power}   # element keys, never ids
  final_state:
    - in: settings.battery
      expect: {low_power: true}
  unchanged: [settings.network, settings.display]
  oracle:                              # the author's solution over stable keys
    - click: settings.battery.low_power
    - finish: true
  optimal: {steps: 2}                  # set by the build from the oracle
  max_steps: 6
  split: dev
  core: true
```

The full key list is in `edat/screen/cases/schema.py` (`CASE_KEYS`) and
`edat/screen/README.md`.
